# User Stories

This folder holds audience stories for personal PR templates and future client work.

- `jnap-root.user-stories.json` is the machine-readable story map.
- `jnap-root.user-stories.md` is the readable review copy.
- `user-story-map.schema.json` defines the reusable story map contract.

Pitches should cite story IDs through `research_basis`. Requirements should cite story IDs through `source_story_ids`.
