# JNAP Design Bibliography

Status: active

This bibliography is the research baseline for Justin's root site, reusable personal PR templates, and future client design pitches. JSON remains the source of truth at `src/design-templates/research/jnap-design-bibliography.json`; this Markdown file is the readable review copy.

## Reference Sites

- **Paco Coursey**: Direct personal index where work, writing, now, and contact do the credibility work. Use this for simple signal density and plain labels. Avoid copying developer-only category language. https://paco.me/
- **Brian Lovin**: Personal operating-system reference where writing, projects, tools, listening, and identity coexist. Use this for living-index structure. Avoid making the root feel like only a blog. https://brianlovin.com/
- **Agencies | Joe Coleman**: Terse proof-list reference. Use this for confidence through direct listing. Avoid desktop-only density. https://getcoleman.com/agencies/
- **Anime.js**: Interactive craft reference. Use this for motion that rewards poking and stays modular. Avoid motion required for comprehension. https://animejs.com/
- **Rauno Freiberg**: Sparse personal signature reference. Use this for authored restraint. Avoid copying aphorism structure. https://rauno.me/
- **Derek Sivers**: Plain personal archive reference. Use this for broad but legible personal information architecture. Avoid text-heavy root overload. https://sive.rs/
- **Tania Rascia**: Personal creative-corner reference. Use this for normal human breadth with clear public boundaries. Avoid unreviewed personal texture. https://www.taniarascia.com/me/

## Methods And Standards

- **A Brief History & Ethos of the Digital Garden**: Basis for docs/wiki as evolving, linked, contextual knowledge. https://maggieappleton.com/garden-history
- **WCAG 2.2**: Accessibility baseline for structure, keyboard access, focus visibility, target size, text alternatives, and non-interfering motion. https://www.w3.org/TR/WCAG22/
- **Design Tokens Format Module 2025.10**: Stable token format for scalable colors, typography, spacing, and cross-template portability. https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/
- **What Are User Stories?**: User-centered story pattern for turning audience intent into build requirements. https://www.interaction-design.org/literature/topics/user-stories
